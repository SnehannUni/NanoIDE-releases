# Cube

Cube is a small, fast desktop IDE around Claude Code.

## Download

**[Download Cube for Windows](https://github.com/SnehannUni/NanoIDE-releases/releases/latest)** (the `-setup.exe` under Assets)

Installs for your user, no admin rights needed. You need [Claude Code](https://docs.claude.com/en/docs/claude-code) installed and logged in once (`claude`).

Windows may warn that the installer is from an unknown publisher (it is not code-signed yet): choose *More info → Run anyway*.

## Updates

Cube updates itself: it looks for a new version every time it starts and every 30 minutes while it runs. Updates are signed and verified before they install.

All versions are listed under [Releases](https://github.com/SnehannUni/NanoIDE-releases/releases).
